# Interpretation Guide for LFP Validation Results

This document explains how to interpret the metrics generated by `compare_files.py` after LFP extraction.

---

# Example Output

```text
Correlation: 0.9916
SNR (Raw): 9.97 dB
SNR (LFP): 11.21 dB
Mean Coherence: 0.9041
Median Coherence: 0.9365
Max Coherence: 0.9999 at 0.0 Hz
```

---

# Metric Interpretation

## 1. Correlation

### Definition
Correlation measures the similarity between the downsampled raw signal and the extracted LFP signal in the time domain.

### Interpretation
- `1.0` → Signals are nearly identical
- `> 0.95` → Excellent preservation of signal structure
- `0.8 - 0.95` → Acceptable but may contain distortions
- `< 0.8` → Potential filtering or processing issues

### Example
```text
Correlation: 0.9916
```

This indicates excellent preservation of temporal structure after filtering and downsampling.

### What Low Correlation May Indicate
- Incorrect channel count
- Filtering instability
- Chunk boundary artifacts
- Aliasing
- Corrupted input/output files

---

# 2. Signal-to-Noise Ratio (SNR)

## Definition
SNR estimates the ratio between meaningful neural signal and background noise.

Higher SNR generally indicates cleaner signals.

## Interpretation
### Raw SNR
Represents the broadband signal before LFP extraction.

### LFP SNR
Represents the signal after low-pass filtering and downsampling.

### Expected Behavior
The LFP SNR is typically expected to improve slightly because:
- High-frequency noise is removed
- Spike-band activity is attenuated
- Filtering suppresses broadband artifacts

### Example
```text
SNR (Raw): 9.97 dB
SNR (LFP): 11.21 dB
```

This indicates that the extraction pipeline successfully improved signal quality.

### Warning Signs
If LFP SNR becomes significantly worse than raw SNR:
- Filter parameters may be incorrect
- Numerical instability may exist
- Data corruption may have occurred

---

# 3. Coherence

## Definition
Coherence measures frequency-domain similarity between the original and extracted signals.

Values range from:
- `1.0` → Perfect spectral agreement
- `0.0` → No spectral relationship

## Interpretation
### Mean Coherence
Average spectral similarity across frequencies.

### Median Coherence
Robust estimate of spectral preservation.

### Example
```text
Mean Coherence: 0.9041
Median Coherence: 0.9365
```

These values indicate strong preservation of spectral information.

### Expected Ranges
- `> 0.9` → Excellent
- `0.8 - 0.9` → Good
- `< 0.8` → Potential spectral distortion

### Low Coherence May Indicate
- Aliasing
- Poor filter design
- Incorrect downsampling
- GPU chunk discontinuities
- Numerical precision issues

---

# 4. Maximum Coherence

## Example
```text
Max Coherence: 0.9999 at 0.0 Hz
```

This is expected because low-frequency and DC components are usually preserved extremely well after LFP extraction.

High coherence near 0 Hz generally indicates stable baseline preservation.

---

# Recommended Validation Workflow

## 1. Check Correlation
Ensure:
```text
Correlation > 0.95
```

## 2. Check Coherence
Ensure:
```text
Mean coherence > 0.9
```

## 3. Compare PSDs
Inspect power spectral density plots to verify:
- Proper low-pass filtering
- No unexpected attenuation
- No aliasing artifacts

## 4. Inspect Chunk Boundaries
Visually inspect for:
- Sudden discontinuities
- Periodic artifacts
- Baseline jumps
- Ringing artifacts

This is especially important for GPU chunk-based processing.

## 5. Validate Ripple Preservation
For hippocampal ripple analysis:
- Verify ripple amplitude preservation
- Verify ripple frequency preservation
- Compare ripple-band filtered traces

---

# Interpretation for Ripple Analysis

Typical ripple frequencies:
```text
100–250 Hz
```

With:
```text
Original sampling rate: 30000 Hz
Target sampling rate: 1250 Hz
Cutoff frequency: 450 Hz
```

The extracted LFP should preserve:
- Theta oscillations
- Gamma activity
- Sharp-wave ripples
- Replay-related activity

because the Nyquist frequency after downsampling is:
```text
625 Hz
```

which remains safely above ripple frequencies.

# Typical Indicators of a Successful Pipeline

A successful extraction pipeline typically shows:

| Metric | Expected Value |
|---|---|
| Correlation | > 0.95 |
| Mean Coherence | > 0.90 |
| Median Coherence | > 0.90 |
| SNR | Similar or improved after extraction |
| PSD | Similar below cutoff frequency |

---

# Common Failure Signatures

| Symptom | Possible Cause |
|---|---|
| Low correlation | Wrong channel count |
| Low coherence | Aliasing or filter instability |
| Periodic artifacts | Chunk boundary problems |
| Ripple attenuation | Overly aggressive filtering |
| Baseline shifts | Incorrect filter state propagation |
| Spikes in PSD | Numerical instability |

---

# Conclusion

High correlation and coherence values indicate that the LFP extraction pipeline preserves both:
- temporal structure
- spectral content

while reducing high-frequency noise and enabling efficient downstream electrophysiological analyses.
